# AI Phishing Detection

## About the Project

AI Phishing Detection is a web-based application designed to help users identify suspicious and potentially phishing URLs.

## Features

- 🔍 URL phishing detection
- 🛡️ Fake URL awareness
- 📧 MailGuard scanner
- 🧠 Phishing awareness quiz
- 🌐 Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

AI-Phishing-Detection/
├── index.html
├── script.js
├── style.css
└── README.md

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a URL in the URL checker.
4. Click **Check** to view the result.

## Purpose

The project aims to create awareness about phishing attacks and help users recognize suspicious URLs and online threats.
